TRANSPARENCIA DOCUMENTAL

Fuentes y referencias

Este proyecto constituye un desarrollo independiente para la consulta de la Lengua de Señas Mexicana (LSM). Las ilustraciones, la estructura de datos, la organización del sitio y la plataforma informática son desarrollos propios.

Cuando una ficha se basa en una fuente documental, se indica la obra y la página correspondiente para facilitar la localización y trazabilidad del concepto. Las descripciones publicadas en este sitio han sido sintetizadas, reorganizadas y estructuradas con fines de consulta; no reproducen literalmente el contenido de las obras citadas.

Las imágenes utilizadas en este proyecto son elaboraciones propias y no corresponden a las fotografías ni a las ilustraciones de las fuentes documentales consultadas.

Fuente documental inicial

Diccionario de Lengua de Señas Mexicana de la Ciudad de México. En cada registro se conservará la página de referencia correspondiente.
